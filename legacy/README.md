# Tidigare Python-version

`python/` bevarar den tidigare koden, labbverktygen och testerna som referens.
Den ingår inte i Go-imagen. Följ rotens README och START_HAR.md för nya
installationer. De äldre guiderna beskriver äldre inloggningssidor och ska inte
användas som instruktion för Go-versionen. Äldre bildlänkar kan avse rotens assets/.
